# Hypothesis: Crypto/DeFi Automation with Haiku

## Core Insight
Haiku excels at:
- Classification & routing (which transaction type? which chain?)
- Data extraction (pull contract details, parse blockchain events)
- Content generation (write DAO proposals, governance summaries)
- High-volume, low-complexity tasks

Crypto projects need:
- Transaction analysis & classification
- Smart contract monitoring & alerts
- DAO proposal writing/analysis
- Governance document automation
- Token holder communication

## Potential Angles
1. **Smart Contract Documentation** — Extract ABI, generate human-readable docs (Haiku good fit)
2. **DAO Governance Automation** — Summarize proposals, draft governance docs
3. **Transaction Monitoring/Alerts** — Classify on-chain transactions, trigger actions
4. **Token Holder Analytics** — Profile holders, segment for communications
5. **Bridge/Cross-Chain Analysis** — Route crypto operations, detect patterns

- Josh has deep crypto expertise (can guide research)
